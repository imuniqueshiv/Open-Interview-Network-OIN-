# Trust, safety and fairness

| Risk | Control |
| --- | --- |
| Harassment in a room | One-click report and leave; instant block; either person can end; ladder warning→ban; conduct rating after every session |
| Safety (esp. women) | Campus pools by default; optional verified / same-gender interviewer filters; observer mode with both people’s consent |
| Impersonation | Library avatars only; visible avatar badge; pseudonyms cannot copy existing members |
| Scams / fake recruiters | No job postings or recruiter messaging; no links/contact in chat for new accounts; in-room reminders never pay or share documents |
| Stalking / unwanted contact | No private messaging in v1; no contact exchange; blocked users never match again |
| Recording without consent | OIN records nothing; partner local capture still possible — CoC forbids; privacy notice says we cannot prevent it |
| Thin moderator evidence | Reports, timestamps, repeated-report patterns, fast removal — privacy trade-off accepted |
| Minors | **18+ only** at launch with DOB gate |
| Biased interviewers | Public rubric; fairness checklist; calibration; random sample of feedback |
| Abuse of free resources | Turnstile; per-account and per-network rate limits; quota governor |
| Moderation capacity | Trained volunteers above trust threshold; CoC; appeals; stated response time (e.g. 24h — assumption) |

Publish a grievance contact and takedown address from day one. Publish aggregate moderation numbers each quarter.
