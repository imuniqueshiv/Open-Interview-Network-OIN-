# Question card template

## Fields

- Title  
- Role and level  
- Round (aptitude, GD, technical, HR)  
- Company-type tag  
- The question  
- What a strong answer covers  
- **3–6 expected key points**, each with synonyms and Hinglish variants (used by the Coach engine)  
- Common weak answers  
- Three-step follow-up ladder; each step linked to the key point it probes  
- Rubric criteria tested  
- Source and licence  
- Reviewer and version  

## Content rules

- No leaked papers  
- No confidential assessment content  
- No recruiter names  
- No copying from paid courses  
- Reviewers check each card like a pull request  
- Future CI: every card must have key points + ladder
