# Interviewer Kits and certification

Main fix for weak peer feedback. Every interviewer — including first-year volunteers — gets a kit.

## Kit contents

- Opening script and closing script
- 8–10 question cards for the chosen role, each with:
  - expected-answer notes (key points the Coach engine also uses)
  - ladder of follow-ups
- Rubric with score anchors — [rubric.md](rubric.md)
- Fairness checklist: do **not** ask about caste, religion, marital status, or family plans; judge content, not accent or college
- Timing guide and feedback template

## Certification

1. ~20-minute module  
2. Short quiz  
3. Calibration: score **three** pre-recorded answers vs reference scores  

**Pass:** within one rubric point on ≥70% of criteria (same bar as H6).

Certified members get a badge. Teachers/seniors can add a **verified** badge via college-email or alumni check.

## Phase 0 deliverable (Kit v0)

Two templates:

1. Campus technical  
2. HR / behavioural  

~10 cards each with 3–6 key points; **6 calibration clips** with reference scores.
