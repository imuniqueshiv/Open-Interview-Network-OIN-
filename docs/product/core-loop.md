# Core loop and the 48-hour promise

## Loop

**Prepare** (profile, target role, resume on device) → **Practise** (human or on-device AI) → **Review** (rubric + evidence) → **Give** (interview someone else or add a question card) → **Repeat**.

Everything in the product should shorten time from sign-up to the first real human session.

## First 48 hours

1. **Minutes 0–10.** Sign in with Google or email magic link; college-email verification later for a verified badge. Pick target (campus drive / internship / promotion) and comfort level. Run a 20-second device/network check; say which features will work.
2. **Minutes 10–20.** Record a 3-minute drill. STT + scoring on device. Transcript, rubric report, one thing to fix. Hook costs the project nothing.
3. **Same day.** Book next Mock Interview Night or 1:1 with a senior. Reminders: email, web push, or Telegram.
4. **Session.** 30 minutes with a person — timer, cards, rubric. See [session-script.md](session-script.md).
5. **Within 24 hours.** Both sides submit feedback → unlocks next match.
6. **After.** Offer invite via share link the member sends from their own phone (growth loop). No automated WhatsApp.

## Sign-in (v1.1.2)

- Google OAuth and email magic link
- College-email verification for badges
- **No SMS** (costs money)

## Degraded human session

If WebRTC cannot connect, either person pastes any meeting link. OIN still hosts timer, rubric, notes, and cards. A worse medium beats a cancelled session.
