# Mock Interview Night run sheet

Example timing — confirm with students.

| Time | Activity |
| --- | --- |
| 6:00 | Check-in and technical check |
| 6:15 | Briefing and pairing |
| 6:25–6:55 | Round one |
| 6:55–7:05 | Swap and break |
| 7:05–7:35 | Round two (roles swapped) |
| 7:35–7:50 | Written feedback |
| 7:50–8:00 | Wrap-up, invitations for next partner, next Night |

## Roles on the night

- Host  
- Moderator  
- Technical helper  
- Drill desk (laptop with on-device drill) for anyone whose partner does not arrive within five minutes  

## Phase 0

Hold at least one **manual** Night on a meeting tool or in a lab using Kit v0 and a paper rubric — learn before software exists.
