# 30-minute session script

| Minutes | Step | Notes |
| --- | --- | --- |
| 0–2 | Welcome | Both confirm comfort level, that OIN records nothing, and ground rules |
| 2–5 | Warm-up | “Tell me about yourself” |
| 5–20 | Core | Technical or project deep dive from the kit, with follow-up ladders |
| 20–25 | Behavioural | One STAR question |
| 25–27 | Candidate questions | Practise asking good questions |
| 27–30 | Feedback | Candidate **self-scores first**, then interviewer: scores, one strength, one improvement, one drill |

Written feedback from both sides within **24 hours** unlocks the next match.
