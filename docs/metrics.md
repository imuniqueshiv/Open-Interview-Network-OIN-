# Measuring impact

Measure learning and community health, not sign-ups.

**North star:** interviews completed per active learner per month.

Numbers below are **starting hypotheses** — replace after the pilot; do not publish targets before then.

| Metric | Definition | Starting hypothesis |
| --- | --- | --- |
| Interviews per active learner | Completed human + AI sessions / active learners that month | ≥3 / month |
| Human share of practice minutes | Minutes with a person / all practice minutes | ≥60% by month 3 |
| Session completion | Sessions that reach end / sessions that start | ≥70% |
| Connect success | Connect within 30s | ≥95%, then ≥98% |
| Time to first sessions | Sign-up → first drill; → first human | Drill ≤24h; human ≤48h |
| Repeat rate | Second session within 14 days | ≥40% |
| Comfort progression | Level 1–2 → 3–4 within 8 sessions | ≥40% |
| Rubric growth | Comparable scores first → fifth session | Positive on most criteria |
| Self-reported confidence | 5-point before/after | Rising over five sessions |
| No-show rate | Booked human sessions missing a partner | &lt;20% |
| Invite conversion | Invited partners who join / active learner | ≥0.5 |
| Interviewer certification | Active learners certified in 3 months | 1 in 5 |
| Coach agreement | vs human raters on gold set | ≥70%; never lower than last release |
| Free-quota headroom | Lowest remaining share across quotas at peak | ≥30% |
| Relay share | Sessions that needed TURN | Track; plan capacity |
| Colleges self-hosting | Federation instances | Count by phase |

## Knowing whether it works

- **Baseline:** split pilot into two waves; external rater scores standard mock at start and week 4; compare practised vs waiting.  
- **Sample size:** 50–100 is a learning signal, not proof — say so.  
- **Outcomes:** optional survey at 3 and 6 months on shortlists/offers — do not claim causation.  
- **Equity cuts:** college tier/city, gender, language, **device type** (on-device AI equity).  
- **Open reporting:** aggregate quarterly impact report; no individual data.
