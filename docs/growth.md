# Growth engine

A launch event is not a growth plan. Build loops so each session creates the next.

## Seven loops

| Loop | How | Metric (hypothesis) |
| --- | --- | --- |
| Pair | After session, share link from member’s phone → pre-booked slot | ≥0.5 invited partners join per active learner |
| Interviewer | Giving interviews → certification/badge; seniors bring students | 1 in 5 active learners certified in 3 months |
| Cohort | College circles, shared calendar, cohort-level stats; weekly Night | 30% of college’s active learners attend ≥1 Night/month |
| Content | Cards + approved experience notes under CC BY-SA; indexable static pages | Organic question-bank visits |
| Share | Opt-in progress card image for WhatsApp status / LinkedIn | Share rate among members with ≥5 sessions |
| Open source | good-first-issue, contributor guide, FOSS United / coding clubs | Outside contributors / quarter |
| Federation | College runs OIN in a box; contributes cards/interviewers | Colleges with own instance |

## Channels (cost-effectiveness order — all free)

1. Placement cells and faculty coordinators  
2. Student clubs and campus ambassadors (contribution certificates)  
3. Telegram for reminders/Night; WhatsApp groups members join voluntarily — **admins post by hand**; no automated WhatsApp  
4. Short demos on LinkedIn / Instagram / YouTube  
5. Alumni associations (interviewer supply)  
6. OSS / developer communities  

## Pilot funnel (assumption)

| Step | Of 100 reached |
| --- | --- |
| Sign up | 60 |
| Finish first drill | 45 |
| Book human session | 30 |
| Attend | 24 |
| Second session within 14 days | 10 |

## Retention without dark patterns

Fixed weekly Night; next-best drill from weakest criterion; drive-calendar reminders; gentle streaks that pause during exams. No buying XP/badges/trust; no guilt notifications.

## Timing

Many engineering colleges run final-year drives in the first half of the academic year. Pilot should serve pre-final and final-year students before the next drive season (confirm per college).

## Partnerships

T&P cells (e.g. colleges around RGPV Bhopal), state skill missions, alumni networks, NGOs for first-generation graduates, OSS foundations. Keep OIN brand separate from Hyper Learning Tech; agree in writing if communities overlap.
