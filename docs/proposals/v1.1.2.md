## What changed from v2

| Area | v2 | v1.1.2 | Trade-off |
| --- | --- | --- | --- |
| Real-time media | LiveKit Cloud → self-host later | Browser WebRTC + free STUN/TURN; optional self-hosted LiveKit | 1:1 and groups ≤4 on free path; 5–6 need optional node |
| Sign-in | Google or phone code | Google + email magic link + college-email verify | No SMS |
| Backend | Next.js server, Postgres, Redis, S3 | Static Next.js + Supabase free; self-hostable | Idle pause → keepalive + backups |
| Async AI | Hosted STT + LLM | On-device Coach + optional small on-device LLM | Structured, less chatty; one-time download |
| Live AI interviewer | LiveKit Agents / GPU | Turn-based scripted-adaptive in browser | ~2–4s turn gap (assumption) |
| Server AI | Hosted / rented GPU | Optional community nodes + capped Workers AI overflow | Best-effort; never critical path |
| Reminders | Email + WhatsApp | Email SMTP free, web push, Telegram, ICS, manual WhatsApp share | No automated WhatsApp |
| Money | Institution plan, Season Pass, AI credits | No paid tier; donations/grants optional | Growth via federation |
| Hosting | LiveKit Cloud → India servers | Free hosts + college self-host | Capacity ceiling per deployment |

## Zero-cost rule

1. No fixed cost and no per-use cost in the core loop.  
2. Everything we ship is open source (AGPL / Apache-MIT / CC BY-SA).  
3. Free service only if: no card, plan B exists, quota guard in code.  
4. Core loop = human with human — survives losing any one free provider.  
5. Non-free items: free route or optional — see [../operations/cost-model.md](../operations/cost-model.md).

## What stays the same

Open source, reciprocity, comfort ladder, privacy by default, no monetising personal data, public rubric, Interviewer Kits, 48-hour promise, phase gates that can stop cheaply.
